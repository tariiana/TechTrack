ИНСТРУКЦИЯ ПО ИЗМЕНЕНИЮ СТИЛЕЙ, ШРИФТОВ, ЦВЕТОВ

Для того чтобы изменить цвета, шрифты: у нас есть файл frontend/src/style.css - в нём храняться все глобальные стили приложения
Так же есть файл frontend/src/styles/config.css - в нём при необходимости можно поменять цвет, шрифт, тени и тд.
При изменении стилей в данном файле они изменяются везде.
